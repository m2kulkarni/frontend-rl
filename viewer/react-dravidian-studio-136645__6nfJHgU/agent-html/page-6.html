Commission Enquiry
Site visits across the southern peninsula are undertaken on retainer. Preliminary drawings are rendered within forty days of agreement.
DESPATCH ENQUIRY

Particulars to Enclose

  1. Site dimensions, with cardinal orientation marked from the morning shadow.
  2. Intended deity (mūla-vigraha) and any existing utsava-mūrti to be retained.
  3. Proposed consecration muhūrta, by name of the family astrologer.
  4. Trust deed reference or temple denādhīkana letter, where applicable.
  5. Photographs of any pre-existing structure requiring reconstruction.
  6. Ledger reference of advance retainer (₹ 25,000 against site survey).
